Sambungkan & amankan

1 · Koneksi Google Sheet

Setelah simpan, panel otomatis pindah ke mode Online dan menarik data dari Sheet.

2 · Kode backend (Code.gs)

Tempel kode ini ke project Apps Script saat setup (lihat panduan di bawah). Samakan TOKEN-nya dengan kolom di atas.

const SHEET = 'Pendaftar';
const TOKEN = 'pec-secret-2025'; // samakan dgn admin.html

const ss = () => SpreadsheetApp.getActiveSpreadsheet() || (() => {
  const f = DriveApp.getFilesByName('PEC Pendaftar DB');
  return f.hasNext() ? SpreadsheetApp.open(f.next()) : SpreadsheetApp.create('PEC Pendaftar DB');
})();

function out(o){ return ContentService.createTextOutput(JSON.stringify(o)).setMimeType(ContentService.MimeType.JSON); }

function doGet(e){
  if (e.parameter.token !== TOKEN) return out({ok:false, error:'token salah'});
  const sh = ss().getSheetByName(SHEET);
  const rows = sh.getDataRange().getValues(); rows.shift();
  return out({ok:true, data: rows.map(r => ({
    id:r[0], tanggal:r[1], nama:r[2], wa:r[3], sekolah:r[4], alasan:r[5], program:r[6], tipe:r[7]
  }))});
}

function doPost(e){
  const d = JSON.parse(e.postData.contents);
  if (d.token !== TOKEN) return out({ok:false, error:'token salah'});
  const sh = ss().getSheetByName(SHEET) || ss().insertSheet(SHEET)
    .appendRow(['id','tanggal','nama','wa','sekolah','alasan','program','tipe']);
  sh.appendRow([d.id, d.date, d.name, d.phone, d.school, d.reason, d.program, d.type]);
  return out({ok:true});
}

3 · Ganti sandi admin

4 · Panduan setup (dari HP)

  1. Buka script.google.com di Chrome (login akun Google). Kalau tampilan sesak, aktifkan “Situs desktop” di menu ⋮.
  2. New project → hapus isi editor → tempel kode Code.gs di atas → ganti nilai TOKEN → simpan (ikon disket).
  3. Klik Deploy → New deployment → ikon gerigi → pilih Web app. Isi: Execute as: Me, Who has access: Anyone.
  4. Klik Deploy → Authorize access → pilih akun → Allow (Google akan memperingatkan “unverified app” — klik Advanced → Go to project; ini aman karena skrip milikmu sendiri).
  5. Salin Web app URL (berakhiran /exec) → tempel ke kolom nomor 1 di atas → Simpan → Tes koneksi.
  6. Selesai! Sheet bernama “PEC Pendaftar DB” dibuat otomatis di Google Drive-mu setiap ada pendaftar baru.

Catatan kejujuran

Sandi di halaman ini hanya layar penjaga sisi klien — siapa pun yang membaca kode sumber bisa melewatinya. Yang benar-benar melindungi data adalah: URL Apps Script yang tidak disebar, token rahasia, dan fakta bahwa halaman ini noindex. Untuk kebutuhan klub, kombinasi ini umumnya cukup.
